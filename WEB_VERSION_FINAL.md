# 🌐 Aetheria Graph - Web Version Implementation

## ✨ Огляд змін

Веб-версія додатку створена як **тестова демо-версія без підключення до бази даних**, з красивою стартовою сторінкою та спрощеним функціоналом для демонстрації основних можливостей.

---

## 🎯 Реалізовані вимоги

### 1. ✅ Відключення Supabase для веб-версії
- **Файл:** `lib/main.dart`
- Supabase ініціалізується **ТІЛЬКИ** для мобільних платформ
- Веб-версія працює без бази даних (тестовий режим)

```dart
if (!kIsWeb) {
  await dotenv.load(fileName: ".env");
  await Supabase.initialize(
    url: dotenv.env['SUPABASE_URL'] ?? '',
    anonKey: dotenv.env['SUPABASE_ANON_KEY'] ?? '',
  );
}
```

### 2. ✅ Красива стартова сторінка (як на скріні)
- **Файл:** `lib/web_splash_page.dart`
- Анімовані концентричні кола з неоновим ефектом
- Градієнтний фон (фіолетовий → чорний)
- Кнопка "GET STARTED" з неоновим свіченням
- Текст: "Aetheria Graph", "CYBERPUNK ZEN", "Find peace in the noise"

**Особливості:**
- Анімація кіл з пульсацією (4 секунди цикл)
- Центральна світна точка
- Градієнтна кнопка з тінню
- Версія: "Web Demo v1.0.0"

### 3. ✅ Сторінка налаштувань замість профілю
- **Файл:** `lib/web_settings_page.dart`
- **3 основні функції:**

#### 🌍 Зміна мови
- Вибір між English та Українська
- Візуальні індикатори вибраної мови
- Миттєва зміна мови без перезавантаження

#### 🌙 Зміна теми
- Dark Immersion (AMOLED Black #000000)
- Light mode (Deep Black #121212)
- Перемикач з анімацією

#### 🎮 Easter Egg гра
- Активується після **7 натискань** на версію додатку
- Лічильник: "X more taps..."
- Запускає CyberRunnerGame
- Без збереження результатів у веб-версії

## ⚙️ Технічні деталі

### Platform Guards
```dart
// Supabase тільки для мобільних
if (!kIsWeb) {
  await Supabase.initialize(...);
}

// Роутинг
home: kIsWeb ? const WebSplashPage() : const AuthGate()
```

### State Management
- **Riverpod** для глобального стану
- `localeProvider` - зміна мови
- `darkImmersionProvider` - зміна теми
- Збереження в `SharedPreferences` (працює на веб)

### Локалізація
- Повна підтримка EN/UK
- Динамічна зміна без перезавантаження
- Всі тексти через `AppLocalizations.of(context)!`
